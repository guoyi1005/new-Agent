## 八、清理时的注意事项

1. **`.m2`、`uploads`、`output`、`docs` 等已在 `.gitignore` 里但仍被跟踪**，直接删文件不会从版本库移除，
   需要 `git rm -r --cached <path>` 才会真正干净。
2. **`ai-servers/presenton_runtime/` 与 `Frontend/src/open-source/AIResume/` 是第三方运行时**，
   删除会直接破坏 PPT 生成和 AI 简历功能。
3. **`docs/` 里混着两份东西**：小程序时期的技术文档（可清理）与合规材料（`compliance/` 下的
   AI Coding 披露、开源合规）——清理前先把合规部分挑出来。
4. **`deploy/` 与 `AppBackend/01_roles.sql`、`02_test_users.sql`** 属于当前作品的部署与测试数据，不要误删。
5. 建议顺序：先删 `mini_program_app/` 与后端小程序专用接口 → 跑一次前端构建与后端测试 →
   再删 `docs/output/artifacts/evaluation/designs/design-system/scripts`。
6. `观测` 文件里有真实 Langfuse key，无论是否清理作品，都建议先轮换该密钥。
